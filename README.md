# Azure Cloud Portfolio

## Overview

This project is my personal Azure Cloud Portfolio, built to demonstrate my cloud engineering and web development skills. It is hosted as a static website on Microsoft Azure and showcases my projects, technical skills, certifications, and learning journey.

The goal of this project is to gain hands-on experience with Azure services while building a professional portfolio that reflects real-world cloud engineering practices.

## Technologies Used

* Microsoft Azure Storage
* Azure Static Website Hosting
* HTML5
* CSS3
* JavaScript (ES6)
* Git
* GitHub

## Features

* Responsive portfolio website
* Dynamic Skills section generated with JavaScript
* Dynamic Project Cards generated from JavaScript objects
* GitHub Repository and Live Demo links for each project
* Clean and modern user interface

## Project Goals

This project is part of my journey towards becoming a:

* Junior Cloud Engineer
* Azure Engineer
* Cloud Support Engineer
* DevOps Engineer
* Site Reliability Engineer (SRE)

It also supports my preparation for the Microsoft AZ-900: Azure Fundamentals certification.

## Future Improvements

The following features will be added as the project progresses:

* CI/CD pipeline with GitHub Actions
